DEV_ZHENGZHIN V29 — GITHUB PAGES
1. Giải nén ZIP.
2. Trong repository GitHub, xóa hoặc ghi đè index.html, apps.js và các file cũ tương ứng.
3. Upload TẤT CẢ file trong thư mục V29 vào ROOT của repository (cùng cấp index.html).
4. Commit changes, đợi Actions thành công, sau đó tải lại trang bằng Ctrl+Shift+R hoặc cửa sổ ẩn danh.
5. Danh sách IPA: chỉnh apps.js, chỉ thêm liên kết thật. V29 không tạo app và URL giả.
6. Nhạc nền chỉ phát khi người dùng bấm 'Vào Website Ngay', theo chính sách trình duyệt.
7. Bộ đếm lượt xem thật không có trong bản này vì cần backend.
Lưu ý: design-reference.png là ảnh concept tham khảo, không phải giao diện chạy; giao diện thực là index.html.
